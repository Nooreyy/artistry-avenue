# Artistry Avenue

Artistry Avenue is a modern and responsive stationery e-commerce frontend built with React, Vite, Tailwind CSS, and React Router.

## Features

- Responsive modern UI
- Home page
- Products page
- About page
- Login and Register pages
- Product cards
- Category sections
- Newsletter section
- Responsive navigation
- Reusable React components

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Project Status

Frontend completed. Backend integration can be added in future.
